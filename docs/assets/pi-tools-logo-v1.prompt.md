# pi-tools logo v1

Adopted as the `pi-tools` project identity. The full logo appears in the [root README](../../README.md); the square icon is available for avatars and other compact placements.

Generated with Pi's `codex_generate_image` tool using the Codex backend.

Style reference: upstream pi-ask banner, https://github.com/eko24ive/pi-ask/blob/f5881a65a686740bcef85629a10604723f0125e7/docs/media/pi-ask-main.png

## Final backend prompt

Create one finished bitmap logo lockup on a uniform near-black background #090D0A, canvas approximately 1536x1024. Center a horizontal logo with generous negative space. Left: an isolated roughly square emblem, strong silhouette, modular pixel-built terminal utility toolbox/tool-case symbol in vivid phosphor lime green. Integrate a geometric pi-inspired handle into the toolbox silhouette (handle suggests pi through squared vertical supports and top bar), but not a standalone pi logo. Emblem must feel like a small developer toolkit/toolbox, not chat; legible at 48px; use very few substantial pixel-grid shapes, crisp blocky edges, consistent pixel modules. Add restrained darker-green pixel accents inside emblem for depth, flat graphic style.

Right: wordmark exactly “pi-tools” once, lowercase, bold custom pixel-grid monospace typography, crisp and highly readable, matching lime green, balanced optical weight with emblem. Leave a generous clear gap between emblem and wordmark so emblem can be cropped cleanly. Overall atmosphere: dark terminal, luminous lime palette, carefully drawn pixel typography. Avoid copying reference: no speech bubble, no question mark, no >? symbol, no slogan, no extra text, no feature icons, no annotations. No gradients, no blur-heavy neon glow, no screen noise, no ornamental circuit lines, no 3D mockup, no watermark, no border, no variations. Polished flat graphic logo only.
