请求类型

非工具调用请求：完整响应可确认没有工具调用。含工具调用请求：至少包含一次工具调用，文字与调用混合也归此类。其他（无法判定）：缺少响应、无法可靠关联、旧汇总或尚不支持分类的来源。

整条请求 usage 互斥归类，三类合计等于总量，不逐工具分摊，不表示工具自身用量。占比是含缓存 Token 比例，不是请求次数。Pi / Oh My Pi、Claude Code、Codex、ZCode 和 Kimi Code 已支持有证据的分类：Codex 使用单次响应边界并核对完成账本；ZCode 精确关联 message_id；Kimi 匹配 step 完成证据。不把整个 turn 或相邻工具当作一次请求。累计回退、缺边界、关联冲突、损坏记录及其他未接入来源仍归其他。旧报告需重新读取日志才能补出分类。

日期、分位与模型计价

按报告时区归入日期；无记录可能是未使用、日志缺失或读取不全，不能自动视为零。截止日可能未结束。报告是主动查询快照，不做后台更新。

默认仅有用量日，无记录日按 0 纳入是显式假设。Min / P25 / P50 / P75 / P90 / Max 使用同一样本；分位采用线性插值，各指标不一定来自同一天，极值不是预算边界或预测。完整日金额分位排除未完整定价日期，可能产生样本偏差。

模型计价固定当前筛选的每天四类 Token，逐日按本报告用过的目标模型费率重新计价，然后计算分位，不把各类 Token 的分位乘价相加。目标费率齐备即可模拟，不要求原模型已定价。这不是实际节省、质量或速度预测。

执行效率

执行视图仅使用原生 Pi 的 assistant 响应边界与 exec / wait 证据。已记录 assistant 响应不是完整 HTTP/API 请求数，也不是计费次数；其他 Harness 与旧导入没有 execution 证据时显示为无数据，不显示为 0。

精确 exec 直方图只纳入已完成且可核对的执行单元；pending、unknown 不按零处理。均值、中位数与 P75 仅使用精确样本；批处理覆盖 = ≥2 个内层工具的精确 exec / 精确 exec 总数；精确样本覆盖 = 精确 exec / 已记录 exec（包括 pending 和 unknown）。模式字段是观察到的 code_mode、other_tools、no_tools、unknown 证据，不自动代表配置、实验组、质量、速度或节省。

incompleteToolCalls、nestedToolErrors 和 shellNonzero 受 trace 丢弃与不完整影响，均为观察到的下限；页面不据此推断成功率或失败率。

导出与隐私

Token 明细与顶部下载 CSV 按日期 × Harness × 模型 × 项目 × 终端 × 请求类型聚合；同目录 details.csv / usage.json 保持原始粒度。执行视图的专用 CSV 按响应保留白名单统计、直方图与哈希，不含工具参数、结果或原始 ID。Harness 对应 source 字段，亦包括 Cursor 等来源。

保留来源级去重，不推断工时或模型级会话用量；会话时长仅保留在本地 JSON / sessions.csv，执行摘要直接按响应中的会话哈希分组。来源读取可联网，采集结果不上传；本 HTML 不发起网络请求。
